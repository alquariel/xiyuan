# Thermal Camera Runtime Files

Place the Hikvision thermal camera runtime folder here:

```text
lib/sensors/thermal_camera/lib/win
```

The application expects `HCNetSDK.dll`, `PlayCtrl.dll`, the matching OpenSSL DLLs, and the Hikvision SDK dependency folders in that runtime directory.

These files are not generated by the C++ build. Add only vendor runtime files that are allowed by the Hikvision license for your deployment.
